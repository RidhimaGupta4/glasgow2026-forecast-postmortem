# docs

The interactive dashboard, served by GitHub Pages.

| File | Purpose |
|---|---|
| `index.html` | A single self-contained page, generated by `src/cgpm/dashboard.py` from `results/`. It loads nothing from the network |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are |

**To publish it:** on GitHub, go to **Settings → Pages**, set the source to "Deploy from a branch", and choose branch `main` and folder `/docs`. The site appears at `https://ridhimagupta4.github.io/glasgow2026-forecast-postmortem/`.

Do not edit `index.html` by hand; it is rewritten on every run. `tests/test_dashboard.py` checks its numbers against `results/metrics.json`.
