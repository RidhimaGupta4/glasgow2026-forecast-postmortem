# results

Generated by `make results` (or `python -m cgpm.pipeline`). Do not edit by hand: every file is overwritten on each run, and a test checks that a fresh run reproduces the committed tables.

| Path | Contents |
|---|---|
| `metrics.json` | Every headline number in one file: scores, intervals, paired differences, ceiling, tie counts, B2 coefficients, seeds, and per-nation ranks |
| [`tables/`](tables/) | All tables as CSV |
| [`figures/`](figures/) | The six figures used in `REPORT.md` and the main README |

Random seeds are fixed (bootstrap 20260722, permutation 20260723), and library versions are pinned in `requirements.txt`, so results are reproducible exactly.
